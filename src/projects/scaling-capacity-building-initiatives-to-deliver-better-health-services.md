## Project Description

Understanding the urgent need for a comprehensive capacity-building programme tailored for the nursing staff in India, PPHF is building a program that aims to build a proof of concept at the Rajiv Gandhi Super Specialty Hospital, Raichur, Karnataka and scale up the interventions at multiple other locations across the country.

## Project Objectives

- Develop and implement a specialized training curriculum for nurses in Cardiology, Oncology, and Maternal Health.
- Train nurses at Rajiv Gandhi hospital, Raichur, using an interactive and participatory methodology.
- Establish a scalable model for the training program for implementation across nursing colleges nationwide.
